# Описание
Хельхейм реализует комплексное ПО для одностронней синхронизации файловой структуры.

Он представляет собой 2 программы:
- `sender` занимается мониторингом файловой структуры, и в случае выявления изменений отправляет информацию об измененных файлах и их событиях
- `recipient` является слушателем, который принимает информацию об измененных файлах и повторяет изменения
